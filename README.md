링클은 긴 URL을 간단히 공유하거나 조건에 맞는 단축 도구를 찾으려는 사람을 위한 서비스입니다.
7주차의 URL 단축과 복사 페이지에, 다른 단축 서비스를 검색하는 목록을 추가했습니다.

메인에서 아래로 스크롤하거나 화살표를 누르면 목록으로 이동합니다.
스크롤을 내린다는 것은, 무언가 정보가 더 필요한 사람의 행동이기 때문에, 
검색어와 다양한 정렬을 통해 원하는 단축링크 서비스를 찾을 수 있습니다.

직접 테스트했을 때 검색 기능과 단축링크 기능이 잘 작동했습니다.
검색결과가 없거나, 필터를 바꾸다가 취소해도 기존 조건이 유지되는 것에 집중하여 개발했습니다.
URL이나 설정을 바꾸면 이전 결과가 지워지는 것도 확인했습니다. 
데스크톱과 모바일에서 조작도 확인했습니다.
