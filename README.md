## 9주차: 서비스 제보 폼

목록 위 `+` 버튼에서 서비스를 제보하거나 정보를 수정할 수 있게 했습니다. 수정을 누르면 기존 이름 칸이 나오고, 추가로 바꾸면 숨겨지면서 입력도 막힙니다. 제보 내용은 브라우저에만 저장됩니다.

이름은 2~80자, 내용은 10~500자이고 앞뒤 공백은 뺍니다. 주소는 500자 이내의 HTTP/HTTPS만 받으며, 아이디나 비밀번호가 들어간 주소는 막았습니다. 글자 수와 입력 상태를 보여주고, 저장 중에는 버튼을 누를 수 없게 했습니다.

### 확인 순서

1. 빈칸이나 잘못된 주소로 저장해보고, 내용을 고쳤을 때 오류가 없어지는지 확인했습니다.
2. 추가와 수정을 바꿔 기존 이름 칸이 나오고 숨겨지는지 확인했습니다.
3. 저장한 뒤 다시 작성을 눌러 처음 상태로 돌아오는지 확인했습니다.

PC와 모바일에서 확인했고 영어 화면도 같이 봤습니다. 저장 공간을 가득 채웠을 때도 입력은 남아 있었고, 공간을 비우고 다시 시도하니 저장됐습니다.
