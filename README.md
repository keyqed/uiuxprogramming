# 나의 첫 웹페이지

UI/UX 프로그래밍 1주차의 개념을 바탕으로 만든 기초 웹페이지입니다.
교안의 지정 완성본을 복제한 것이 아니라 HTML, CSS, JavaScript의 역할을 살펴보도록 구성한 실습 예제입니다.

## 구성

- `index.html`: 제목, 내비게이션, UI·UX 설명, 기술 선택 버튼과 설명 영역
- `style.css`: 색상, 여백, 레이아웃, 모바일 화면 대응, 키보드 포커스 표시
- `script.js`: 버튼 클릭 시 설명과 선택 상태 변경

## 실행

`index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행합니다. 별도 설치나 빌드가 필요하지 않습니다.

## 확인할 동작

1. HTML, CSS, JavaScript 버튼을 누르면 설명과 코드 예시가 변경됩니다.
2. 선택된 버튼 하나가 초록색으로 표시됩니다.
3. Tab 키로 이동하고 Enter 또는 Space 키로 버튼을 누를 수 있습니다.
4. 좁은 화면에서는 콘텐츠가 한 열로 배치됩니다.

## 학습 메모

UI는 사용자가 보고 조작하는 요소이고, UX는 서비스를 이용하는 전체 경험입니다.
이 페이지에서는 선택 상태와 설명을 즉시 바꾸어 사용자 행동에 피드백을 제공합니다.

참고: 「UI/UX 프로그래밍」 1주차 교안의 UI·UX 개념 및 웹 화면의 3층 구조. 교안 원본은 저장소에 포함하지 않습니다.
